🛡️ Machine Learning Security Research Project

Phishing Website
Detection

Enter a website URL. The system fetches the page, extracts URL and webpage signals, and classifies it as phishing or legitimate using an XGBoost model.

For safety, the scanner only analyzes publicly reachable HTTP/HTTPS pages. Never enter passwords or payment details into a site just because the model says legitimate.
XGBoost • 30-feature phishing dataset • CV-derived decision threshold • Research/demo use
